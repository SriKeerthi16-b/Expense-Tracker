# ExpenseTracker

ExpenseTracker is a modern, responsive web application that helps you easily track and manage your daily expenses. Add expenses with details like amount, category, date, and description. Visualize spending trends with interactive charts and set budgets to stay on top of your finances. Import/export your data as JSON for backup and sharing.

## Features

- Add, edit, and delete expenses with amount, category, date, and optional description  
- Set monthly budgets for different categories with progress indicators  
- Filter expenses by category and date range  
- Sort expenses by date, amount, or category  
- View spending breakdown by category and monthly trend charts using Chart.js  
- Export expenses data to JSON file and import from JSON for easy data management  
- Responsive and clean UI, works well on desktop and mobile devices  

## Technologies Used

- HTML5  
- CSS3 (with custom variables and responsive design)  
- JavaScript (vanilla, for app logic and interactivity)  
- Chart.js (for dynamic charts and data visualization)  
- FontAwesome (for icons)  

## How to Use

1. Clone or download this repository.  
2. Open `index.html` in any modern web browser.  
3. Use the form to add expenses.  
4. Manage budgets in the Budget Settings section.  
5. Filter and sort expenses as needed.  
6. Export your data for backup or import data from JSON files.

## Folder Structure

- `index.html` — main HTML file  
- `style.css` — styles and responsive design  
- `app.js` — JavaScript functionality (make sure to include it if not present)
